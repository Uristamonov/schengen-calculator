# 🇪🇺 Schengen Short-Stay Monitor & Predictive Planner

An advanced, interactive 18-month timeline calculator specifically engineered for multi-stay property owners and long-term short-stay travelers to ensure seamless alignment with Schengen area travel limits [Vercel].

## ✨ Core Features
*   🎛️ **Draggable Timeline Canvas:** Directly grab, click, and slide the highlighted blue 180-day window block overlay horizontally with your mouse cursor to shift evaluation metrics fluidly [Vercel].
*   🛡️ **30-Day Safety Predictor:** Constantly evaluates scheduled upcoming trip segments to catch future overstay risks an entire month in advance.
*   🎛️ **Plan My Year Continuity Stress Testing:** Automatically sweeps across all 18 months of your layout strategy to search for hidden calendar rolling window traps.
*   ✏️ **Inline Logs Modifier Panel:** Modify, update, or remove travel records directly inside the data log dashboard cards using inline forms.
*   🔒 **Device Isolation Privacy:** All travel segment profiles save and cache automatically inside your own local browser data sandbox.

## 🚀 Technology Stack
*   **Framework Core:** React 18 (Functional State Hooks)
*   **Compilation Pipe:** Vite
*   **Infrastructure Hosting:** Vercel Edge Server Engine [Vercel]
